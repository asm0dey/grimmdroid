# Page Curl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Apple-Books-style page curl over the stock Readium navigator, for finger drags, flicks, volume keys and edge taps, with a user-set speed for turns that play by themselves.

**Architecture:** A `TurnOverlay` view wraps the navigator container. It keeps pictures of the previous/current/next page, drawn ahead of time from the chapter WebViews (whole-document drawing), and plays a vendored, patched OpenGL curl over them while Readium jumps instantly underneath. A pure `TurnSession` state machine decides when the curl may be removed; a pure `CurlGeometry` holds the patched curl math.

**Tech Stack:** Kotlin, Readium kotlin-toolkit 3.4.0, vendored `irurueta-android-gl-curl` 1.1.6 sources + `com.irurueta:irurueta-android-glutils:1.1.11`, DataStore, Compose (settings), Kotest + Robolectric.

**Spec:** `docs/superpowers/specs/2026-10-23-page-curl-design.md`

## Global Constraints

- Readium stays 3.4.0, unforked. minSdk 26.
- Vendored curl files keep their Apache-2.0 headers; every change is marked with a `// grimmdroid:` comment; add a `NOTICE` entry for the curl library.
- New Kotlin files carry the project's GPL header (copy from any existing file).
- Tests: Kotest `FunSpec` for pure logic, Robolectric JUnit4 for views (follow `SettingsStoreSpec` / `StatusBarLifecycleTest`). No production interface or wrapper that exists only for tests; inject behaviour as constructor lambdas.
- Page turn setting values: `NONE`, `SLIDE`, `CURL`; new installs default `SLIDE`; existing installs (a current account is set when the migration first runs) get `SLIDE` if the old switch was on, else `NONE`.
- Turn speed: 200–1000 ms, default 450 ms; applies to turns that play by themselves. Finger release finishes in 150 ms.
- Curl only in paginated, left-to-right, horizontal, one-column layout; otherwise CURL behaves as SLIDE.
- `WebView.enableSlowWholeDocumentDraw()` runs in `Application.onCreate` for everyone (cost accepted, but measured and reported).
- The status line and every locator consumer show the page the user sees: no locator update reaches them mid-turn, and a cancelled turn records no visit.

## Review Focus

1. Long-press text selection, then a horizontal drag: must extend the selection, never start a curl. → Task 6 test `selection blocks takeover`.
2. Turns requested while one is running (key mashing, swipe during the finishing animation): ignored, never a stuck cover. → Task 5 test `second turn while busy is ignored` and `paint never arrives → curl removed after timeout`.
3. Activity paused or rotated mid-turn: the overlay is removed and the navigator stays where it is. → Task 5 test `abort removes the curl and keeps the navigator page`.
4. First page of the book going back / last page going forward: no cover, no curl, no jump. → Task 5 test `no neighbour at the book's edge → nothing happens`.
5. Font/theme/margin change between turns: a stale picture is never shown. → Task 4 test `invalidate drops all pictures`, Task 7 wires invalidation to preference changes.

### Task 3: Patch the curl: geometry, no catch-up, clean finish

**Files:**
- Create: `app/src/main/kotlin/com/irurueta/android/gl/curl/CurlGeometry.kt`
- Modify: `app/src/main/kotlin/com/irurueta/android/gl/curl/CurlTextureView.kt`, `CurlMesh.kt`, `CurlPage.kt`
- Test: `app/src/test/kotlin/com/irurueta/android/gl/curl/CurlGeometrySpec.kt`

**Interfaces:**
- Produces (all in renderer coordinates, page rect `left..right`, `top`/`bottom` as the library uses them):
  - `internal object CurlGeometry`
  - `fun fold(pointerX: Float, pointerY: Float, anchorX: Float, anchorY: Float, radius: Double, pageLeft: Float): Fold` — `data class Fold(val x: Float, val y: Float, val dirX: Float, val dirY: Float, val radius: Double)`. Plain floats, so the spec runs without Robolectric. Forward: `anchor` = drag start on the right edge. Backward: `anchor` = (page right, drag start y). The fold sits halfway between anchor and pointer, less half the cylinder length (`radius * PI`), i.e. the library's two-page translate rule; below one cylinder length it uses the library's sine rule; radius is clamped to `pos.x - pageLeft`.
  - `fun release(pointerX: Float, forward: Boolean, pageLeft: Float, pageRight: Float): Release` — `data class Release(val completed: Boolean, val targetX: Float)`. Forward completes when `pointerX < (pageLeft + pageRight) / 2`, backward when `pointerX > ` it. Target x for "fold on the left edge" is `pageLeft - (pageRight - pageLeft)`; for "fold on the right edge" `pageRight`.
  - `CurlTextureView.turnListener: ((completed: Boolean) -> Unit)?` — called once per curl, on the UI thread, after the finishing animation's last frame is drawn.
  - `CurlTextureView.setPage(index: Int, bitmap: Bitmap)` — replaces one page's texture; uploads only that texture, on the next frame.
  - `CurlTextureView.releaseDurationMs: Int` — finishing animation after a finger release (default 150).
  - `CurlTextureView.autoTurn(forward: Boolean, durationMs: Int)` — a turn that plays by itself along a path from near the bottom corner (forward: 97 % width / 88 % height → −90 % / 72 %; backward mirrored), accelerate-decelerate, ending with the completed callback; no synthetic touch events.

- [ ] **Step 1: Write the failing tests** (`CurlGeometrySpec`, Kotest, page `-1f..1f`):
  - `"forward fold is halfway between edge and finger"`: anchor `(1,0)`, pointer `(-0.2,0)`, radius 0 → `x shouldBe (0.4f plusOrMinus 1e-4f)`.
  - `"backward fold mirrors forward"`: anchor `(1,0)` (page right), pointer `(0.2,0)` → `x shouldBe (0.6f plusOrMinus 1e-4f)`.
  - `"fold leans with a diagonal drag"`: anchor `(1,-0.8)`, pointer `(0,-0.6)` → `dirY` is non-zero and has the sign of `pointerY - anchorY`.
  - `"radius never pushes the cylinder past the left edge"`: pointer near the left edge → `radius <= x - pageLeft`.
  - `"release past the middle completes forward, before it cancels"` and the backward mirror; `"complete target puts the fold on the left edge"`: `fold(targetX, …).x shouldBe (pageLeft plusOrMinus 1e-3f)`.

- [ ] **Step 3: Implement `CurlGeometry`.**

**Interfaces:**
- Produces:
  - `enum class Side { PREVIOUS, CURRENT, NEXT }`
  - `class PagePictures(private val container: View)` with `fun refresh()` (redraws all three; runs on the main thread, after the navigator's layout), `fun invalidate()` (drops all), `operator fun get(side: Side): Bitmap?` (null = missing), `val generation: Int` (bumped by `refresh`/`invalidate`).

- How pictures are drawn (decided, not left open):
  - The visible chapter WebView: the `WebView` descendant of `container` whose global visible rect is non-empty.
  - Chapter neighbours: the `androidx.viewpager.widget.ViewPager` descendant's children; the one whose `left == pager.scrollX + pager.width` is next, `- pager.width` previous; its `WebView` descendant draws page `0` (next) or its last page (`computeHorizontalScrollRange() / width - 1`, previous).

  - A picture that `isBlank()` is stored as missing.

  - `"invalidate drops all pictures"`: after `invalidate()`, all three `get` return null and `generation` increased.

**Interfaces:**
- Consumes: nothing from earlier tasks (pure).
- Produces:
  ```kotlin
  class TurnSession(
      private val scope: CoroutineScope,
      private val jump: suspend (forward: Boolean) -> Boolean, // instant Readium turn; false at the book's edge
      private val awaitPainted: suspend () -> Unit,
      private val onCover: (Boolean) -> Unit,                // show/hide the curl layer
      private val onSettled: (turned: Boolean) -> Unit,       // release locator gating
      private val paintTimeoutMs: Long = 1500,
  )
  ```
  `val busy: Boolean`; `fun start(forward: Boolean, jumpNow: Boolean, hasPicture: Boolean, onReady: () -> Unit): Boolean` (false → busy, caller does nothing); `fun passedMiddle(passed: Boolean)`; `fun curlFinished(completed: Boolean)`; `fun abort()`.
- Rules: automatic turns pass `jumpNow = true`; drags jump on the first `passedMiddle(true)` and jump back on a later `passedMiddle(false)`. `onReady` runs at once when `hasPicture`, else after the jump has painted (then the caller snapshots the new page and builds the curl). The cover is removed only when the curl has finished **and** the jump has painted, or `paintTimeoutMs` elapsed. A cancelled turn whose jump happened jumps back and waits for paint first. A `jump` returning false ends the turn silently.

  - `"cancelled turn after a jump jumps back, waits for paint, then uncovers"`.
  - `"no neighbour at the book's edge → nothing happens"`: automatic turn, `hasPicture = false`, `jump` returns false → `onReady` never called, cover never shown, `onSettled` not called, `busy` false.
  - `"second turn while busy is ignored"`: `start` returns false.
  - `"paint never arrives → curl removed after timeout"`: `awaitPainted` suspends forever → cover hidden after 1500 virtual ms.
  - `"abort removes the curl and keeps the navigator page"`: abort mid-turn → cover hidden, no further `jump` calls, `onSettled(false)`.
